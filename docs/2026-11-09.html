01 Hacker News

Claude Fable 5.2 and Mythos 5.2

Anthropic released Claude Fable 5.2 and Claude Mythos 5.2, which are the same underlying model with different safeguards: Fable has strong cybersecurity and biology protections and is available to all users, while Mythos is available to organizations in beneficial cybersecurity or biomedical work through Anthropic's verification programs. The company says the new models improve on coding, reasoning, and vision, and in prerelease testing they helped engineers complete software migrations, designed three working electronic devices, solved two open problems in black hole physics, and formalized the proof of Fermat's Last Theorem in 30 hours. The models generate outputs up to 30% faster than the previous versions and cost less, at $8 per million input tokens and $40 per million output tokens, with an optional fast mode at double those prices. Anthropic says prerelease safety testing found high-stakes misalignment risks remain low, and Fable 5.2's safeguards produce fewer unnecessary blocks. The models score above Anthropic's Opus 5.5 on almost all benchmarks tested, though the company recommends most users start with Opus 5.5 for everyday coding and knowledge work and move up to Fable or Mythos for more ambitious technical projects.

11 Ars Technica

Claude Code is accidentally exposing secrets all over GitHub

Security researchers at Apiiro found that Anthropic's Claude Code tool has been leaking sensitive information onto public GitHub repositories. When users approve automated commands with "Yes, and don't ask again," the command—including any embedded passwords or API tokens—is often saved as-is in a local settings file called ".claude/settings.local.json." Anthropic says this file is added to a global .gitignore list, but that protection doesn't apply at the repository level, so the file can be uploaded accidentally, and Claude Code sometimes commits it without user input. Apiiro found over 100,000 cases of the settings file on public GitHub repos, of which about 1,100 from 63 organizations contained secrets like API tokens, database passwords, or private keys. Even after files are removed, the secrets can persist in forks of the original project.
