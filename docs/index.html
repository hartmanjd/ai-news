01 Hacker News

The 'Astra can read and write weights to improve Qwen' post is misleading

A post claiming that “Astra can read and write weights to improve Qwen” is misleading because its headline result does not come from reading raw weights alone. The article says the Qwen3.5-0.8B math fix, which raised MATH-500 from 7.9% to 48.1%, actually used Python programs and up to 50 passes of running the model on practice problems. Only three experiments, on small networks of 17K to 172K weights, worked directly from raw weights with no tools. Every experiment involving a real language model used Python, and the game-writing results were mixed, with one network beating PPO only on Breakout. The author argues these are different techniques that should not be presented together, since combining them would imply a deeper capability than was shown.

02 Hacker News

Postman silently auto-installs AI plugins and attempts to share all API data

A user reported that opening the Postman desktop app on a Mac automatically installed Postman plugins into other coding tools, including Codex and Claude Code, without asking. Postman's own logs recorded the automatic install, and the user found that Codex's global config had been changed to enable a Postman plugin and trust a startup hook. The installer source also tries to approve its own hook, and a remote Postman MCP connection was enabled but failed with an authentication error. The user calls this a serious consent and trust-boundary problem and asks Postman to stop automatic installs, remove self-approval of hooks, and provide a full uninstall path; the report does not claim data was actually exfiltrated.

04 Hacker News

Qwen 3.8 27B on my laptop can interpret model weights, too

A new paper by Rikiya Takehi, Jayden Teoh, Alex Zhang, and Omar Khattab found that frontier models like GPT-6 Astra can interpret and edit the raw weights of neural networks without running code, a capability they call Weight-Space Programming. In one example, Astra fixed a reasoning-loop problem in Qwen3.5-0.8B by editing 0.016% of its weights, raising its MATH-500 score from 7.9% to 48.1%. The author of the article then tested the paper's game-identification prompt on Qwen 3.8 27B running locally on a laptop, and the model correctly identified Pac-Man, Pong, and Breakout from weights alone, though it failed on the more obscure Freeway. Some critics, including spaCy author Matthew Honnibal, called the paper misleading for conflating what models can do with raw weights versus what they can do with code and tools. The author says the results are interesting but does not think they justify claims that source code is becoming obsolete.

05 Hacker News

Scaling Git at OpenAI

OpenAI has built a new backend for Git repositories called Pando to handle the growing size and demands of its monorepo, which increased sharply as Codex enabled engineers to work in parallel. Pando now powers all development in OpenAI's monorepo without changing how the team uses Git, and it keeps compatibility with the Git protocol and client. In production, Pando cut median push latency by nearly 5x and now delivers nearly a petabyte of Git data per day. OpenAI said its existing systems had struggled with slow fetches and pushes, failed merges, and reliability sometimes below 90%. Pando is designed to scale writes across branches in parallel and to serve reads from shared packfiles, so many clients can download the same data with little computation. OpenAI says it will keep contributing improvements to Git upstream to support agent-scale work.
